# Eval usage window

Before an eval run over about USD 20, check how much of the 5-hour usage window is left, split the run or start it in a fresh window, and save the handoff before heavy spending, because about USD 73 of runs used up the window, five runs errored on the limit and the session was cut off before its handoff.
