# Trigger description edits

When editing a skill's trigger description, change only the clause under test, keep every existing trigger phrase, and include the previously passing cases in the verification run, because a reworded draft dropped phrases the passing cases rely on and the planned check would not have caught a loss of the 24 of 24 fires.
