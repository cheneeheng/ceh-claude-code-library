# Reference skill sources

When a reference skill collection is treated as a gold standard, still weight its parts by evidence and say which parts fail the assumption instead of copying its patterns wholesale, because some of its older skills use ALL-CAPS headings and one description breaks the 1024-character limit its own validator enforces.
