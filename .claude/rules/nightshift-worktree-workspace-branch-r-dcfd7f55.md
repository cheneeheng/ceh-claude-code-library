# Worktree workspace branch

When a worktree session creates workspace files, say upfront that they stay on the paired workspace branch until fast-forwarded from the main checkout and give the exact command at the start, because an audit file and backlog rows could not reach the main workspace checkout and the user had to ask for the pull.
