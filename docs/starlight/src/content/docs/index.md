Plugins for Claude Code that guide autonomous agents, delivered as skills, subagents, and hooks.
Each plugin is a standalone use case, and you install only the ones you need.

This site is an experiment and covers three plugins. The pages under **Plugins** are the plugins'
own READMEs, rebuilt on every deploy.

| Plugin                                                                                 | Use it for                                                     |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [`ceh-every-session`](/ceh-claude-code-library/starlight/plugins/ceh-every-session/)   | Habits that hold however Claude Code is used                   |
| [`ceh-coding-conduct`](/ceh-claude-code-library/starlight/plugins/ceh-coding-conduct/) | The behavioral contract and minimalism rules for coding agents |
| [`ceh-git-workflow`](/ceh-claude-code-library/starlight/plugins/ceh-git-workflow/)     | Commits, pull requests, changelogs, and reviews                |

Full catalog and install guide: see the
[repository](https://github.com/cheneeheng/ceh-claude-code-library).
