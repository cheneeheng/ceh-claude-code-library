skills-sync

Serverless GUI for installing, updating, adding, and removing Claude Code skills in .claude/skills/. Uses the File System Access API and the GitHub REST API. No data leaves your browser except requests to api.github.com when using a GitHub source.

Requires a Chromium-based browser — File System Access API not available. This page cannot continue.
